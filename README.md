# URL Shortener

A simple URL Shortener application built with Node.js, Express.js, MongoDB, and ShortID.

## Features

- Generate unique short URLs
- Redirect to original URL
- MongoDB Atlas Integration
- REST API
- Input Validation

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- ShortID
- HTML
- CSS
- JavaScript

## Installation

```bash
git clone https://github.com/harshvarma3695/url_shortener.git
cd url_shortener
npm install
npm start
```
